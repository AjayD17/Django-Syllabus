========================================================
1. DJANGO FORMS
========================================================

Definition:
Django Forms are used to take input from users and process
the data safely.

--------------------------------------------------------
WHY FORMS ARE IMPORTANT?
--------------------------------------------------------

Forms help to:
    • Collect user data
    • Validate user input
    • Reduce manual coding
    • Improve security

========================================================
SIMPLE FORM EXAMPLE
========================================================

forms.py

from django import forms

class StudentForm(forms.Form):
    name = forms.CharField(max_length=100)
    age = forms.IntegerField()

--------------------------------------------------------
Explanation
--------------------------------------------------------

forms.Form
    → Creates Django form

CharField
    → Text input field

IntegerField
    → Number input field

========================================================

========================================================

</form>

========================================================
OUTPUT
========================================================

Displayed Form:

Age  : [______________]

--------------------------------

========================================================
WHY {% csrf_token %} IS USED?
========================================================

CSRF = Cross-Site Request Forgery

It protects forms from fake requests and cyber attacks.

========================================================
2. FORM VALIDATION
========================================================

Definition:
Form validation checks whether user input is correct or not.

--------------------------------------------------------
WHY VALIDATION IS IMPORTANT?
--------------------------------------------------------

Validation prevents:
    • Empty fields
    • Wrong data types
    • Invalid input
    • Security problems

========================================================
VALIDATION EXAMPLE
========================================================

forms.py

from django import forms

class StudentForm(forms.Form):

    name = forms.CharField(max_length=100)

    age = forms.IntegerField(min_value=18)

========================================================
VALID INPUT
========================================================

Name : Ajay
Age  : 20

--------------------------------------------------------
OUTPUT
--------------------------------------------------------

Form submitted successfully

========================================================
INVALID INPUT
========================================================

Name : Rahul
Age  : 15

--------------------------------------------------------
OUTPUT
--------------------------------------------------------

Ensure this value is greater than or equal to 18.

========================================================
HOW VALIDATION WORKS
========================================================

if form.is_valid():

    print("Valid Data")

else:

    print(form.errors)

--------------------------------------------------------
Explanation
--------------------------------------------------------

is_valid()
    → Checks whether data is valid

form.errors
    → Displays validation errors

========================================================
3. MODELFORM
========================================================

Definition:
ModelForm automatically creates forms from Django models.

--------------------------------------------------------
WHY MODELFORM IS IMPORTANT?
--------------------------------------------------------

Without ModelForm:
    • Need to create forms manually

With ModelForm:
    • Form generated automatically from model

Result:
👉 Less coding

========================================================
MODEL EXAMPLE
========================================================

models.py

from django.db import models

class Student(models.Model):

    name = models.CharField(max_length=100)

    age = models.IntegerField()

========================================================
MODELFORM EXAMPLE
========================================================

forms.py

from django.forms import ModelForm
from .models import Student

class StudentForm(ModelForm):

    class Meta:

        model = Student

        fields = ['name', 'age']

========================================================
OUTPUT
========================================================

Django automatically creates:

--------------------------------
Name : [______________]

Age  : [______________]

        [ Submit ]
--------------------------------

without manually writing form fields.

========================================================
ADVANTAGES OF MODELFORM
========================================================

    • Less coding
    • Faster development
    • Easy database integration
    • Automatic form generation
    • Easy maintenance
