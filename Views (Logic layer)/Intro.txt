========================================================
        VIEWS IN DJANGO – SIMPLE EXPLANATION
========================================================

Views are one of the most important parts of Django.

========================================================
1. WHAT IS A VIEW?
========================================================

Definition:
A View is a Python function or class that contains the
business logic of a Django application.

Views:
    • Receive user requests
    • Process data
    • Return responses

Simple Meaning:
👉 Views control what users see on the website.

========================================================
2. TYPES OF VIEWS IN DJANGO
========================================================

+----------------------+--------------------------------+
| Type                 | Description                    |
+----------------------+--------------------------------+
| Function-Based View  | Simple Python functions        |
| Class-Based View     | OOP style views                |
+----------------------+--------------------------------+

========================================================
3. FUNCTION-BASED VIEW (FBV)
========================================================

Definition:
Function-Based Views are normal Python functions used to
handle requests and return responses.

--------------------------------------------------------
Simple Syntax
--------------------------------------------------------

def home(request):
    return HttpResponse("Welcome")

========================================================
EXAMPLE OF FUNCTION-BASED VIEW
========================================================

views.py

from django.http import HttpResponse

def home(request):
    return HttpResponse("Welcome to Django")

--------------------------------------------------------
URL CONFIGURATION
--------------------------------------------------------

urls.py

from django.urls import path
from . import views

urlpatterns = [
    path('', views.home),
]

========================================================
OUTPUT
========================================================

When user opens:

http://127.0.0.1:8000/

Browser Output:

Welcome to Django

========================================================
HOW FUNCTION-BASED VIEW WORKS
========================================================

Step 1:
User sends request

        ↓

Step 2:
URL calls home() function

        ↓

Step 3:
Function processes request

        ↓

Step 4:
Response returned to browser

========================================================
ADVANTAGES OF FUNCTION-BASED VIEW
========================================================

    • Easy to understand
    • Good for beginners
    • Less code
    • Simple logic handling

========================================================
DISADVANTAGES OF FUNCTION-BASED VIEW
========================================================

    • Difficult for large projects
    • Code repetition may occur
    • Less reusable

========================================================
4. CLASS-BASED VIEW (CBV)
========================================================

Definition:
Class-Based Views are views written using Python classes.

CBVs follow:
👉 OOP (Object-Oriented Programming) concept

========================================================
EXAMPLE OF CLASS-BASED VIEW
========================================================

views.py

from django.http import HttpResponse
from django.views import View

class HomeView(View):

    def get(self, request):
        return HttpResponse("Welcome to Django CBV")

--------------------------------------------------------
URL CONFIGURATION
--------------------------------------------------------

urls.py

from django.urls import path
from .views import HomeView

urlpatterns = [
    path('', HomeView.as_view()),
]

========================================================
OUTPUT
========================================================

When user opens:

http://127.0.0.1:8000/

Browser Output:

Welcome to Django CBV

========================================================
HOW CLASS-BASED VIEW WORKS
========================================================

Step 1:
User sends request

        ↓

Step 2:
URL calls HomeView class

        ↓

Step 3:
get() method handles request

        ↓

Step 4:
Response returned to browser

========================================================
ADVANTAGES OF CLASS-BASED VIEW
========================================================

    • Reusable code
    • Better for large projects
    • Supports inheritance
    • Organized structure
    • Less code duplication

========================================================
DISADVANTAGES OF CLASS-BASED VIEW
========================================================

    • Slightly difficult for beginners
    • More complex than FBV

========================================================
5. FUNCTION-BASED VIEW VS CLASS-BASED VIEW
========================================================

+----------------------+----------------------+----------------------+
| Feature              | Function-Based View  | Class-Based View     |
+----------------------+----------------------+----------------------+
| Structure            | Functions            | Classes              |
| Difficulty           | Easy                 | Moderate             |
| Reusability          | Less                 | High                 |
| Best For             | Small projects       | Large projects       |
| Code Reusability     | Limited              | Better               |
+----------------------+----------------------+----------------------+

========================================================
6. REAL-TIME EXAMPLE
========================================================

Suppose you are building:
    • College Management System

--------------------------------------------------------
Using Function-Based Views
--------------------------------------------------------

    • Student login page

--------------------------------------------------------
Using Class-Based Views

    • Student dashboard

========================================================
7. IMPORTANT METHODS IN CLASS-BASED VIEWS
========================================================

+------------+--------------------------------+
| Method     | Purpose                        |
+------------+--------------------------------+
| get()      | Handles GET requests           |
| post()     | Handles POST requests          |
| put()      | Handles update requests        |
| delete()   | Handles delete requests        |
+------------+--------------------------------+

========================================================
8. FINAL CONCLUSION
========================================================

Views are the logic layer of Django applications.

Types of Views:
    • Function-Based Views (FBV)
    • Class-Based Views (CBV)

Function-Based Views:
    • Simple
    • Easy for beginners

Class-Based Views:
    • Powerful
    • Reusable
    • Better for large applications

Result:
👉 Views help control how data is processed and shown
to users in Django applications.
