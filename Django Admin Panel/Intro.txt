========================================================
        DJANGO ADMIN PANEL – SIMPLE EXPLANATION
========================================================

Django Admin Panel is a built-in dashboard provided by
Django to manage application data easily.

Using Admin Panel, developers and administrators can:
    • Add data
    • View data
    • Update data
    • Delete data

without creating separate frontend pages manually.

========================================================
1. SUPERUSER
========================================================

Definition:
A Superuser is an admin user who has full access to the
Django Admin Panel.

Superuser can:
    • Add data
    • Edit data
    • Delete data
    • Manage users
    • Control the entire application

========================================================
CREATE SUPERUSER
========================================================

Command:

python manage.py createsuperuser

--------------------------------------------------------
Example Input
--------------------------------------------------------

Username: admin
Email: admin@gmail.com
Password: ********

========================================================
OUTPUT
========================================================

Superuser created successfully.

========================================================
LOGIN ADMIN PANEL
========================================================

URL:

http://127.0.0.1:8000/admin/

--------------------------------------------------------
Login Details
--------------------------------------------------------

OUTPUT
========================================================

Admin Dashboard opens successfully.

========================================================
WHY SUPERUSER IS IMPORTANT?
========================================================

Advantages:
    • Full admin access
    • Manage all application data
    • Secure administration

Result:
👉 Easy application management

========================================================
2. REGISTER MODELS
========================================================

Definition:
Registering models means connecting Django models to
the admin panel so data can be viewed and managed.

========================================================
STEP 1 – CREATE MODEL
========================================================

from django.db import models

class Student(models.Model):
    name = models.CharField(max_length=100)
    age = models.IntegerField()

========================================================
STEP 2 – REGISTER MODEL
========================================================

from django.contrib import admin
from .models import Student

admin.site.register(Student)

========================================================
OUTPUT
========================================================

Inside Admin Panel:

    • Student section appears automatically

Admin can:
    • Add student records
    • Edit student records
    • Delete student records

========================================================
WHY REGISTER MODELS IS IMPORTANT?
========================================================

Advantages:
    • Automatically shows database data
    • No need to create separate admin pages
    • Easier database management

Result:
👉 Faster development

3. CRUD OPERATIONS
========================================================

Full Form:
CRUD = Create, Read, Update, Delete

--------------------------------------------------------
Definition
--------------------------------------------------------

CRUD operations are basic database operations used in
almost every web application.

========================================================
a) CREATE
========================================================

Definition:
Adding new data into database.

--------------------------------------------------------
Example
--------------------------------------------------------

Add Student:
    Name = Ajay
    Age  = 20

========================================================
OUTPUT
========================================================

Student record added successfully.

========================================================
b) READ
========================================================

Definition:
Viewing or retrieving data from database.

--------------------------------------------------------
Example
--------------------------------------------------------

View Student Records:

+----+---------+-----+
| id | name    | age |
+----+---------+-----+
| 1  | Ajay    | 20  |
| 2  | Rahul   | 21  |
+----+---------+-----+

========================================================
OUTPUT
========================================================

All student records displayed.

========================================================
c) UPDATE
========================================================

Definition:
Modifying existing data in database.

--------------------------------------------------------
Example
--------------------------------------------------------

Before Update:

Ajay → Age = 20

After Update:

Ajay → Age = 22

========================================================
OUTPUT
========================================================

Student record updated successfully.

========================================================
d) DELETE
========================================================

Definition:
Removing data from database.

--------------------------------------------------------
Example
--------------------------------------------------------

Delete Student:
    Rahul

========================================================
OUTPUT
========================================================

Student record deleted successfully.

Examples:
