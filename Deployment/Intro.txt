========================================================
        DJANGO DEPLOYMENT – SIMPLE EXPLANATION
========================================================

Definition:
Deployment is the process of making a Django web application
available on the internet so users can access it online.

After development in local system:
    • Project must be hosted on a server
    • Users can access using URL

Example:

http://127.0.0.1:8000/
    → Local development server

After Deployment:

https://mywebsite.com
    → Public live website

========================================================
IMPORTANT DEPLOYMENT PLATFORMS
========================================================

    • Heroku
    • AWS
    • PythonAnywhere

========================================================
1. HEROKU
========================================================

Definition:
Heroku is a cloud platform used to deploy web applications
easily.

--------------------------------------------------------
Why Heroku is Popular?
--------------------------------------------------------

    • Beginner friendly
    • Easy deployment
    • Supports Django directly
    • Cloud hosting available

========================================================
BASIC HEROKU DEPLOYMENT COMMANDS
========================================================

Step 1: Install Heroku CLI

Step 2: Login to Heroku

heroku login

--------------------------------------------------------
Output
--------------------------------------------------------

Opening browser for login...
Logged in successfully

--------------------------------------------------------
Step 3: Create Heroku App
--------------------------------------------------------

heroku create myproject

--------------------------------------------------------
Output
--------------------------------------------------------

Creating app... done
https://myproject.herokuapp.com/

--------------------------------------------------------
Step 4: Push Project
--------------------------------------------------------

git push heroku main

--------------------------------------------------------
Output
--------------------------------------------------------

Deployment successful

========================================================
FINAL RESULT
========================================================

Your Django website becomes live online.

Example:

https://myproject.herokuapp.com

========================================================
ADVANTAGES OF HEROKU
========================================================

    • Easy setup
    • Fast deployment
    • Beginner friendly
    • Good for small projects

========================================================
2. AWS (AMAZON WEB SERVICES)
========================================================

Definition:
AWS is a cloud computing platform used for scalable and
large-scale application deployment.

========================================================
WHY AWS IS IMPORTANT?
========================================================

AWS is used for:
    • Large applications
    • Enterprise systems
    • High traffic websites
    • Scalable cloud hosting

========================================================
POPULAR AWS SERVICES FOR DJANGO
========================================================

    • EC2  → Virtual Server
    • S3   → File Storage
    • RDS  → Database Service
    • Load Balancer → Traffic distribution

========================================================
EXAMPLE
========================================================

Suppose:
    • 10 lakh users visit website

AWS can:
    • Increase server resources
    • Handle heavy traffic
    • Prevent server crash

========================================================
OUTPUT
========================================================

Website remains:
    • Fast
    • Stable
    • Available online

========================================================
REAL-TIME COMPANIES USING AWS
========================================================

    • Netflix
    • Amazon
    • Airbnb

========================================================
ADVANTAGES OF AWS
========================================================

    • Highly scalable
    • Secure cloud platform
    • Supports millions of users
    • Reliable infrastructure

========================================================
3. PYTHONANYWHERE
========================================================

Definition:
PythonAnywhere is an online hosting platform specially
designed for Python and Django applications.

========================================================
WHY PYTHONANYWHERE IS POPULAR?
========================================================

    • Very easy for beginners
    • No server configuration needed
    • Direct Python support
    • Simple Django deployment

========================================================
DEPLOYMENT PROCESS
========================================================

Step 1:
Upload Django project

Step 2:
Configure WSGI file

Step 3:
Reload web app

========================================================
OUTPUT
========================================================

Website becomes live online.

Example:

https://ajay.pythonanywhere.com

========================================================
ADVANTAGES OF PYTHONANYWHERE
========================================================

    • Easy to use
    • Beginner friendly
    • Free hosting available
    • Simple Django setup

========================================================
COMPARISON TABLE
========================================================

+------------------+----------------------------------+-----------------------------+

+------------------+----------------------------------+-----------------------------+
