========================================================
    API (DJANGO REST FRAMEWORK) – SIMPLE EXPLANATION
========================================================

API in Django is mainly created using:

Django REST Framework (DRF)

DRF is used to build REST APIs for web and mobile
applications.

========================================================
1. WHAT IS API?
========================================================

Full Form:
API = Application Programming Interface

--------------------------------------------------------
Definition
--------------------------------------------------------

API allows different applications to communicate and
exchange data with each other.

--------------------------------------------------------
Simple Example
--------------------------------------------------------

Suppose:
    • Mobile App requests student data
    • Django server sends student data

Communication happens using API.

========================================================
2. WHAT IS REST API?
========================================================

Full Form:
REST = Representational State Transfer

--------------------------------------------------------
Definition
--------------------------------------------------------

REST API is a web service that allows applications to
send and receive data using HTTP methods.

--------------------------------------------------------
Common HTTP Methods
--------------------------------------------------------

GET
    → Retrieve data

POST
    → Insert data

PUT
    → Update data

DELETE
    → Delete data

========================================================
3. REAL-TIME EXAMPLE OF REST API
========================================================

Suppose you are building:
    • College Management System

Mobile app requests:

GET /students/

Django API sends student data.

========================================================
4. SIMPLE DJANGO MODEL
========================================================

from django.db import models

class Student(models.Model):
    name = models.CharField(max_length=100)
    age = models.IntegerField()

========================================================
5. SERIALIZER
========================================================

Definition:
Serializer converts Django model data into JSON format.

It also converts JSON data back into Python objects.

========================================================
WHY SERIALIZER IS IMPORTANT?
========================================================

Django models cannot be directly sent through API.

Serializer converts:

Python Object
        ↓
JSON Data

========================================================
6. SERIALIZER EXAMPLE
========================================================

from rest_framework import serializers
from .models import Student

class StudentSerializer(serializers.ModelSerializer):

    class Meta:
        model = Student
        fields = '__all__'

========================================================
7. OUTPUT OF SERIALIZER
========================================================

Database Record:

+----+---------+-----+
| id | name    | age |
+----+---------+-----+
| 1  | Ajay    | 20  |
+----+---------+-----+

--------------------------------------------------------
JSON Output
--------------------------------------------------------

{
    "id": 1,
    "name": "Ajay",
    "age": 20
}

========================================================
9. GET API (READ DATA)
========================================================

Definition:
GET method is used to retrieve data.

--------------------------------------------------------
Example
--------------------------------------------------------

from rest_framework.decorators import api_view
from rest_framework.response import Response
from .models import Student
from .serializers import StudentSerializer

@api_view(['GET'])
def get_students(request):

    students = Student.objects.all()
    serializer = StudentSerializer(students, many=True)

    return Response(serializer.data)

========================================================
OUTPUT
========================================================

[
    {
        "id": 1,
        "name": "Ajay",
        "age": 20
    },
    {
        "id": 2,
        "name": "Rahul",
        "age": 21
    }
]
