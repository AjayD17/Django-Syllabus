========================================================
        PYTHON SYNTAX – IMPORTANT CONCEPTS
========================================================

Python Syntax refers to the rules used to write Python
programs correctly.

Important Python Syntax Topics:
    • Variables
    • Loops
    • Functions

These are the basic and most important concepts in Python.

========================================================
1. VARIABLES
========================================================

Definition:
Variables are used to store data values in memory.

--------------------------------------------------------
Syntax
--------------------------------------------------------

name = "Ajay"
age = 20

--------------------------------------------------------
Explanation
--------------------------------------------------------

name
    → Variable name

=
    → Assignment operator

"Ajay"
    → Stored value

--------------------------------------------------------
Example Program
--------------------------------------------------------

name = "Ajay"
age = 20

print(name)
print(age)

--------------------------------------------------------
Output
--------------------------------------------------------

Ajay
20

========================================================
2. TYPES OF VARIABLES
========================================================

--------------------------------------------------------
a) String
--------------------------------------------------------

name = "Ajay"

Stores text data.

--------------------------------------------------------
b) Integer
--------------------------------------------------------

age = 20

Stores whole numbers.

--------------------------------------------------------
c) Float
--------------------------------------------------------

salary = 25000.50

Stores decimal values.

--------------------------------------------------------
d) Boolean
--------------------------------------------------------

is_student = True

Stores True or False values.

========================================================
3. RULES FOR VARIABLES
========================================================

    • Variable names should start with letters
    • Spaces are not allowed
    • Special symbols are not allowed
    • Python is case-sensitive

--------------------------------------------------------
Correct Examples
--------------------------------------------------------

student_name = "Ajay"
age1 = 20

--------------------------------------------------------
Wrong Examples
--------------------------------------------------------

1name = "Ajay"      ❌
student name = ""   ❌

========================================================
4. LOOPS
========================================================

Definition:
Loops are used to repeat a block of code multiple times.

Python mainly provides:
    • for loop
    • while loop

========================================================
5. FOR LOOP
========================================================

Definition:
Used when the number of repetitions is known.

--------------------------------------------------------
Syntax
--------------------------------------------------------

for variable in sequence:
    statements

--------------------------------------------------------
Example
--------------------------------------------------------

for i in range(5):
    print(i)

--------------------------------------------------------
Output
--------------------------------------------------------

0
1
2
3
4

--------------------------------------------------------
Explanation
--------------------------------------------------------

range(5)
    → Generates numbers from 0 to 4

for loop
    → Repeats code 5 times

========================================================
6. WHILE LOOP
========================================================

Definition:
Used when repetition depends on a condition.

--------------------------------------------------------
Syntax
--------------------------------------------------------

while condition:
    statements

--------------------------------------------------------
Example
--------------------------------------------------------

i = 1

while i <= 5:
    print(i)
    i += 1

--------------------------------------------------------
Output
--------------------------------------------------------

1
2
3
4
5

--------------------------------------------------------
Explanation
--------------------------------------------------------

i += 1
    → Increases value by 1

Loop stops when condition becomes False.

========================================================
7. FUNCTIONS
========================================================

Definition:
Functions are reusable blocks of code used to perform
specific tasks.

Functions help:
    • Reduce code repetition
    • Improve readability
    • Organize programs

========================================================
8. FUNCTION SYNTAX
========================================================

def function_name():
    statements

--------------------------------------------------------
Example
--------------------------------------------------------

def greet():
    print("Welcome to Python")

greet()

--------------------------------------------------------
Output
--------------------------------------------------------

Welcome to Python

========================================================
9. FUNCTION WITH PARAMETERS
========================================================

Definition:
Parameters allow values to be passed into functions.

--------------------------------------------------------
Example
--------------------------------------------------------

def add(a, b):
    print(a + b)

add(10, 20)

--------------------------------------------------------
Output
--------------------------------------------------------

30

--------------------------------------------------------
Explanation
--------------------------------------------------------

a and b
    → Parameters

10 and 20
    → Arguments

========================================================
10. RETURN STATEMENT
========================================================

Definition:
return is used to send value back from a function.

--------------------------------------------------------
Example
--------------------------------------------------------

def square(n):
    return n * n

result = square(5)

print(result)

--------------------------------------------------------
Output
--------------------------------------------------------

25
