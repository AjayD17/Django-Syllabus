========================================================
1. WHAT IS A MODULE?
========================================================

Definition:
A module is a Python file that contains:
    • Functions
    • Variables
    • Classes
    • Reusable code

Modules help developers organize code properly.

--------------------------------------------------------
Simple Meaning
--------------------------------------------------------

Instead of writing all code in one file,
Python allows code separation into multiple files.

Each file is called a module.

========================================================
2. WHY MODULES ARE IMPORTANT?
========================================================

Advantages of Modules:
    • Code reusability
    • Better organization
    • Easier maintenance
    • Reduces duplicate code
    • Faster development

========================================================
3. IMPORT SYSTEM
========================================================

Definition:
The import system is used to access code from another
module or library.

Using import:
    • Functions can be reused
    • Built-in libraries can be accessed
    • Large programs become manageable

========================================================
4. SIMPLE IMPORT EXAMPLE
========================================================

--------------------------------------------------------
Step 1: Create Module File
--------------------------------------------------------

File Name:
maths.py

Code:

def add(a, b):
    return a + b

--------------------------------------------------------
Step 2: Import Module
--------------------------------------------------------

main.py

import maths

result = maths.add(10, 20)

print(result)

========================================================
OUTPUT
========================================================

30

========================================================
5. HOW IMPORT WORKS
========================================================

import maths
    → Imports maths module

maths.add(10, 20)
    → Calls add() function from maths module

========================================================
6. BUILT-IN MODULE EXAMPLE
========================================================

Python already provides many built-in modules.

Example:
math module

--------------------------------------------------------
Code
--------------------------------------------------------

import math

print(math.sqrt(25))

========================================================
OUTPUT
========================================================

5.0

--------------------------------------------------------
Explanation
--------------------------------------------------------

math.sqrt(25)
    → Finds square root of 25

========================================================
7. RANDOM MODULE EXAMPLE
========================================================

--------------------------------------------------------
Code
--------------------------------------------------------

import random

print(random.randint(1, 10))

========================================================
OUTPUT
========================================================

7

(Note: Output changes randomly)

--------------------------------------------------------
Explanation
--------------------------------------------------------

randint(1, 10)
    → Generates random number between 1 and 10

========================================================
8. SPECIFIC IMPORT EXAMPLE
========================================================

Instead of importing entire module,
specific functions can be imported.

--------------------------------------------------------
Code
--------------------------------------------------------

from math import sqrt

print(sqrt(64))

========================================================
OUTPUT
========================================================

8.0

--------------------------------------------------------
Explanation
--------------------------------------------------------

from math import sqrt
    → Imports only sqrt() function

========================================================
9. ALIAS IMPORT EXAMPLE
========================================================

Modules can be renamed using alias.

--------------------------------------------------------
Code
--------------------------------------------------------

import math as m

print(m.pow(2, 3))

========================================================
OUTPUT
========================================================

8.0

--------------------------------------------------------
Explanation
--------------------------------------------------------

as m
    → Gives short name to module

pow(2, 3)
    → Calculates 2³
