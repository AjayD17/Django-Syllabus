========================================================
        FILE HANDLING – SIMPLE EXPLANATION
========================================================

Definition:
File Handling is used to:
    • Read data from files
    • Write data into files
    • Update file content
    • Store information permanently

File handling is important because data can be saved
even after the program is closed.

========================================================
WHY FILE HANDLING IS IMPORTANT?
========================================================

File handling is used in:
    • Student Management Systems
    • Banking Applications
    • Attendance Systems
    • Report Generation
    • Data Storage

========================================================
TYPES OF FILE OPERATIONS
========================================================

    • Read File
    • Write File
    • Append File
    • Close File

========================================================
1. WRITE FILE
========================================================

Definition:
Write operation is used to store data into a file.

========================================================
EXAMPLE
========================================================

file = open("student.txt", "w")

file.write("Welcome to Python")

file.close()

========================================================
EXPLANATION
========================================================

open("student.txt", "w")
    → Opens file in write mode

write()
    → Writes data into file

close()
    → Closes file

========================================================
OUTPUT
========================================================

File Created:

student.txt

Content inside file:

Welcome to Python

========================================================
IMPORTANT NOTE
========================================================

"w" = Write Mode

If file already exists:
    • Old data will be removed
    • New data will be written

========================================================
2. READ FILE
========================================================

Definition:
Read operation is used to retrieve data from a file.

========================================================
EXAMPLE
========================================================

file = open("student.txt", "r")

content = file.read()

print(content)

file.close()

========================================================
EXPLANATION
========================================================

"r"
    → Read mode

read()
    → Reads complete file content

print(content)
    → Displays file data

========================================================
OUTPUT
========================================================

Welcome to Python

========================================================
3. APPEND FILE
========================================================

Definition:
Append operation is used to add new data without deleting
existing file content.

========================================================
EXAMPLE
========================================================

file = open("student.txt", "a")

file.write("\nPython File Handling")

file.close()

========================================================
OUTPUT
========================================================

student.txt

Welcome to Python
Python File Handling

========================================================
IMPORTANT NOTE
========================================================

"a" = Append Mode

Old data remains safe.
New data is added at the end.

========================================================
4. READ LINE BY LINE
========================================================

Definition:
Used to read file content line by line.

========================================================
EXAMPLE
========================================================

file = open("student.txt", "r")

for line in file:
    print(line)

file.close()

========================================================
OUTPUT
========================================================

Welcome to Python
Python File Handling

========================================================
5. FILE MODES
========================================================

+------+-------------------------------+
| Mode | Purpose                       |
+------+-------------------------------+
| r    | Read file                     |
| w    | Write file                    |
| a    | Append data                   |
| x    | Create new file               |
+------+-------------------------------+
