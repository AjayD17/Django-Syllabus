========================================================
        OOP CONCEPTS – SIMPLE EXPLANATION
========================================================

OOP = Object Oriented Programming

Definition:
OOP is a programming approach that organizes code using
objects and classes.

Main OOP Concepts:
    • Class
    • Object
    • Inheritance
    • Abstraction
    • Polymorphism
    • Encapsulation

========================================================
1. CLASS
========================================================

Definition:
A class is a blueprint or template used to create objects.

Simple Meaning:
    • Class defines properties and behaviors.

--------------------------------------------------------
EXAMPLE
--------------------------------------------------------

class Student:
    name = "Ajay"

--------------------------------------------------------
Explanation
--------------------------------------------------------

class Student
    → Creates a class named Student

name = "Ajay"
    → Variable inside class

========================================================
WHY CLASS IS IMPORTANT?
========================================================

    • Helps organize code
    • Reusable structure
    • Easier maintenance

========================================================
2. OBJECT
========================================================

Definition:
An object is an instance of a class.

Simple Meaning:
    • Object is a real entity created using class.

--------------------------------------------------------
EXAMPLE
--------------------------------------------------------

class Student:
    name = "Ajay"

s1 = Student()

print(s1.name)

========================================================
OUTPUT
========================================================

Ajay

--------------------------------------------------------
Explanation
--------------------------------------------------------

s1 = Student()
    → Object creation

s1.name
    → Access class variable

========================================================
WHY OBJECT IS IMPORTANT?
========================================================

    • Access class data
    • Perform operations
    • Represents real-world entities

========================================================
3. INHERITANCE
========================================================

Definition:
Inheritance allows one class to acquire properties and
methods from another class.

Simple Meaning:
    • Child class uses parent class features.

--------------------------------------------------------
EXAMPLE
--------------------------------------------------------

class Parent:
    def show(self):
        print("Parent Class")

class Child(Parent):
    pass

c = Child()
c.show()

========================================================
OUTPUT
========================================================

Parent Class

--------------------------------------------------------
Explanation
--------------------------------------------------------

class Child(Parent)
    → Child inherits Parent class

c.show()
    → Access parent method

========================================================
WHY INHERITANCE IS IMPORTANT?
========================================================

    • Code reusability
    • Reduces duplicate code
    • Easier maintenance

========================================================
4. ABSTRACTION
========================================================

Definition:
Abstraction hides internal implementation details and
shows only important functionality.

Simple Meaning:
    • Hide unnecessary details from user.

--------------------------------------------------------
REAL-TIME EXAMPLE
--------------------------------------------------------

ATM Machine:
    • User enters PIN
    • User withdraws money

User does NOT know:
    • Internal banking process
    • Database operations

========================================================
PYTHON EXAMPLE
========================================================

from abc import ABC, abstractmethod

class Vehicle(ABC):

    @abstractmethod
    def start(self):
        pass

class Car(Vehicle):

    def start(self):
        print("Car Started")

c = Car()
c.start()

========================================================
OUTPUT
========================================================

Car Started

========================================================
WHY ABSTRACTION IS IMPORTANT?
========================================================

    • Reduces complexity
    • Improves security
    • Easy for users

========================================================
5. POLYMORPHISM
========================================================

Definition:
Polymorphism allows the same method name to perform
different actions.

Simple Meaning:
    • One method behaves differently in different classes.

--------------------------------------------------------
EXAMPLE
--------------------------------------------------------

class Dog:
    def sound(self):
        print("Dog Barks")

class Cat:
    def sound(self):
        print("Cat Meows")

d = Dog()
c = Cat()

d.sound()
c.sound()

========================================================
OUTPUT
========================================================

Dog Barks
Cat Meows

--------------------------------------------------------
Explanation
--------------------------------------------------------

sound()
    → Same method name

Different outputs
    → Different behavior

========================================================
WHY POLYMORPHISM IS IMPORTANT?
========================================================

    • Flexibility
    • Better code design
    • Easier extension

========================================================
6. ENCAPSULATION
========================================================

Definition:
Encapsulation means wrapping data and methods into a
single unit (class) and restricting direct access.

Simple Meaning:
    • Protect class data from outside access.

--------------------------------------------------------
EXAMPLE
--------------------------------------------------------

class Bank:

    def __init__(self):
        self.__balance = 5000

    def show_balance(self):
        print(self.__balance)

b = Bank()
b.show_balance()

========================================================
OUTPUT
========================================================

5000

--------------------------------------------------------
Explanation
--------------------------------------------------------

__balance
    → Private variable

show_balance()
    → Access private data safely

========================================================
WHY ENCAPSULATION IS IMPORTANT?
========================================================

    • Data security
    • Prevents unauthorized access
    • Better control over data
