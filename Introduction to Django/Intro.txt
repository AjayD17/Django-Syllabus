1.) What is Django? (Detailed Explanation):
    Definition:
        Django is a high-level Python web framework used to build secure, scalable, and fast web applications.
        It follows the MTV architecture (Model–Template–View) and helps developers build backend systems quickly without writing everything from scratch.

    Simple Meaning:
        Django = “Ready-made tools + structure to build websites using Python”

Instead of manually writing:
    database handling
    login system
    URL routing
    security features

    Django already provides them built-in.

    Key Idea of Django:
        Django follows “Don’t Repeat Yourself (DRY)” principle
        ✔ Less code
        ✔ More functionality
        ✔ Faster development

Django Architecture (MTV):
    | Layer    | Role                               |
    | -------- | ---------------------------------- |
    | Model    | Handles database (data)            |
    | Template | Handles UI (HTML pages)            |
    | View     | Handles logic (backend processing) |

Real-Life Analogy:
    Think Django like a restaurant system:
    | Django Part | Real Life                  |
    | ----------- | -------------------------- |
    | Model       | Kitchen (data storage)     |
    | View        | Chef (logic processing)    |
    | Template    | Serving plate (UI display) |

Example 1: Simple Django View:
    from django.http import HttpResponse
    def home(request):    
        return HttpResponse("Welcome to Django!")

Output in browser:
    Welcome to Django!

Example 2: Django Model (Database Table):
    from django.db import models
    class Student(models.Model):    
        name = models.CharField(max_length=100)    
        age = models.IntegerField()

    This automatically creates a database table.

Example 3: URL Routing:
    from django.urls import path
    from . import views
    urlpatterns = [    
        path('home/', views.home),
    ]

When user opens:
    /home/
    Django calls home() function

Example 4: Template (HTML UI):
    <h1>Hello {{ name }}</h1>
    Dynamic page rendering

Example 5: Full Flow (Real Project)
    User → URL → View → Model → Database → Template → Response

Why Django is Powerful?
    ✔ Built-in Admin Panel
    ✔ Security (CSRF, XSS protection)
    ✔ ORM (no need raw SQL)
    ✔ Fast development
    ✔ Scalable for big applications

Real World Applications:
    Django is used in:
        Instagram (backend parts)
        Spotify (data systems)
        YouTube (some services)
        News websites
        E-commerce platforms

Easy Definition (Interview Answer):
    Django is a Python-based web framework that simplifies backend development by providing built-in tools for database management, routing, authentication, and security, enabling rapid development of scalable web applications.
