========================================================
1. BUILT-IN ADMIN
========================================================

Definition:
Django automatically provides an admin panel to manage
application data.

Using admin panel you can:
    • Add data
    • Edit data
    • Delete data
    • View records

without creating separate management pages manually.

========================================================
EXAMPLE
========================================================

Model Creation:

from django.db import models

class Product(models.Model):
    name = models.CharField(max_length=100)
    price = models.IntegerField()

--------------------------------------------------------
Register Model in Admin
--------------------------------------------------------

from django.contrib import admin
from .models import Product

admin.site.register(Product)

========================================================
OUTPUT
========================================================

Django automatically creates:
    • Add Product page
    • Edit Product page
    • Delete Product page

inside:

http://127.0.0.1:8000/admin/

========================================================
WHY IT IS IMPORTANT?
========================================================

Without Admin Panel:
    • Need extra frontend pages
    • More coding required

With Django Admin:
    • Automatic dashboard created

Result:
👉 Saves development time

========================================================
2. ORM (OBJECT RELATIONAL MAPPING)
========================================================

Full Form:
ORM = Object Relational Mapping

--------------------------------------------------------
Definition
--------------------------------------------------------

ORM allows developers to interact with databases using
Python code instead of writing SQL queries manually.

========================================================
WITHOUT ORM (SQL)
========================================================

SELECT * FROM student;

--------------------------------------------------------
Meaning
--------------------------------------------------------

SELECT
    → Retrieve data

*
    → All columns

FROM student
    → From student table

========================================================
WITH DJANGO ORM
========================================================

Student.objects.all()

--------------------------------------------------------
Meaning
--------------------------------------------------------

Student
    → Django model

objects
    → Database manager

all()
    → Fetch all records

========================================================
OUTPUT
========================================================

Database Table:

+----+---------+-----+
| id | name    | age |
+----+---------+-----+
| 1  | Ajay    | 20  |
| 2  | Rahul   | 21  |
+----+---------+-----+

Python Output:

<QuerySet [
    <Student: Ajay>,
    <Student: Rahul>
]>

========================================================
WHY ORM IS IMPORTANT?
========================================================

Advantages:
    • Less coding
    • Easier database handling
    • Faster development
    • Better security
    • Prevents SQL Injection attacks

Result:
👉 Easier and secure database operations

========================================================
3. AUTHENTICATION
========================================================

Definition:
Authentication is the process of verifying whether a user
is valid or not.

Django provides a built-in authentication system.

========================================================
FEATURES OF AUTHENTICATION
========================================================

    • User Login
    • User Logout
    • Password Security
    • User Registration
    • Session Management

========================================================
LOGIN EXAMPLE
========================================================

from django.contrib.auth import authenticate, login

user = authenticate(
    username='ajay',
    password='mypassword'
)

if user is not None:
    login(request, user)

========================================================
OUTPUT
========================================================

If username and password are correct:

    User logged in successfully

If wrong password:

    Invalid login credentials

========================================================
PASSWORD SECURITY
========================================================

Django stores passwords in encrypted format.

Example Stored Password:

pbkdf2_sha256$260000$randomhash...

Passwords are NOT stored as plain text.

========================================================
WHY AUTHENTICATION IS IMPORTANT?
========================================================

Advantages:
    • Secure login system
    • Password protection
    • User management
    • Better application security

Result:
👉 Safe user authentication system
