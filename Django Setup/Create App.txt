========================================================
        CREATE APP IN DJANGO – SIMPLE EXPLANATION
========================================================

Command:

python manage.py startapp app_name

========================================================
1. WHAT IS AN APP IN DJANGO?
========================================================

Definition:
An app in Django is a module or component used to perform
a specific functionality inside a project.

Simple Meaning:
    • Django project can contain multiple apps.
    • Each app handles a specific task.

========================================================
2. REAL-TIME EXAMPLES OF APPS
========================================================

Suppose you are creating:
    • College Management System

Different apps can be:

    • student_app
    • attendance_app
    • faculty_app
    • fees_app

Each app handles separate functionality.

========================================================
3. CREATE APP COMMAND
========================================================

Syntax:

python manage.py startapp app_name

--------------------------------------------------------
Meaning
--------------------------------------------------------

python
    → Runs Python interpreter

manage.py
    → Django management file

startapp
    → Command used to create app

app_name
    → Name of the app

========================================================
4. EXAMPLE
========================================================

Command:

python manage.py startapp student

--------------------------------------------------------
Meaning
--------------------------------------------------------

Creates a new app called:

student

========================================================
5. OUTPUT AFTER EXECUTION
========================================================

Django automatically creates folder structure:

student/
│
├── migrations/
├── __init__.py
├── admin.py
├── apps.py
├── models.py
├── tests.py
├── views.py

========================================================
6. IMPORTANT FILES CREATED
========================================================

--------------------------------------------------------
a) admin.py
--------------------------------------------------------

Used to register models in Django admin panel.

Example:

from django.contrib import admin

--------------------------------------------------------
b) models.py
--------------------------------------------------------

Used to create database tables.

Example:

from django.db import models

class Student(models.Model):
    name = models.CharField(max_length=100)

--------------------------------------------------------
c) views.py
--------------------------------------------------------

Used to write application logic.

Example:

from django.http import HttpResponse

def home(request):
    return HttpResponse("Welcome")

--------------------------------------------------------
d) apps.py
--------------------------------------------------------

Stores app configuration.

--------------------------------------------------------
e) migrations/
--------------------------------------------------------

Stores database migration files.

========================================================
7. AFTER CREATING APP
========================================================

You must add app inside:

settings.py

--------------------------------------------------------
Example
--------------------------------------------------------

INSTALLED_APPS = [
    'student',
]

========================================================
8. WHY CREATE APP IS IMPORTANT?
========================================================

Advantages:
    • Better project organization
    • Easier maintenance
    • Reusable modules
    • Large projects become manageable

========================================================
9. SIMPLE REAL-TIME EXAMPLE
========================================================

Suppose you are building:
    • Online Shopping Website

Different apps can be:

    • product_app

    • cart_app
    • order_app

This makes project clean and organized.

========================================================
10. FINAL CONCLUSION
========================================================

Command:

python manage.py startapp app_name

is used to create a new Django app.

python manage.py startapp student
