========================================================
        RUN SERVER IN DJANGO – SIMPLE EXPLANATION
========================================================

Command:

python manage.py runserver

========================================================
1. WHAT IS RUNSERVER?
========================================================

Definition:
runserver is a Django command used to start the
development server.

Simple Meaning:
    • It runs the Django website locally on your computer.

After running the server:
    • You can open the website in browser
    • Test webpages
    • Check application output

========================================================
2. BREAKDOWN OF THE COMMAND
========================================================

python
    → Runs Python program

manage.py
    → Django management file

runserver
    → Starts Django development server

========================================================
3. WHY RUNSERVER IS IMPORTANT?
========================================================

Without runserver:
    • Django project will not start

With runserver:
    • Website becomes accessible in browser

Result:
👉 Used for testing and development

========================================================
4. HOW TO RUN DJANGO SERVER
========================================================

--------------------------------------------------------
Step 1: Open Terminal
--------------------------------------------------------

Open:
    • CMD
    • PowerShell
    • VS Code Terminal
    • PyCharm Terminal

--------------------------------------------------------
Step 2: Move to Project Folder
--------------------------------------------------------

Example:

cd myproject

--------------------------------------------------------
Step 3: Run Command
--------------------------------------------------------

python manage.py runserver

========================================================
10. STOPPING THE SERVER
========================================================

Press:

CTRL + C

OR

CTRL + BREAK

========================================================
11. COMMON ERRORS
========================================================

--------------------------------------------------------
Error 1:
python not recognized
--------------------------------------------------------

Reason:
    • Python not installed properly

--------------------------------------------------------
Error 2:
No module named django
--------------------------------------------------------

Reason:
    • Django package not installed

Solution:

pip install django

--------------------------------------------------------
Error 3:
Port already in use
--------------------------------------------------------

Reason:
    • Another server using same port

Solution:

python manage.py runserver 8001
