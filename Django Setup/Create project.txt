========================================================
        CREATE PROJECT IN DJANGO – SIMPLE EXPLANATION
========================================================

Command:

django-admin startproject project_name

========================================================
1. WHAT IS A DJANGO PROJECT?
========================================================

Definition:
A Django project is the main container that holds all the
settings, applications, configurations, and files required
for a Django web application.

Simple Meaning:
    • Project = Complete Django Website

Examples:
    • College Management System
    • Online Shopping Website
    • Banking Application
    • Attendance System

========================================================
2. CREATE PROJECT COMMAND
========================================================

Syntax:

django-admin startproject project_name

--------------------------------------------------------
Explanation
--------------------------------------------------------

django-admin
    → Django command-line utility

startproject
    → Creates a new Django project

project_name
    → Name of the project

========================================================
3. EXAMPLE
========================================================

Command:

django-admin startproject collegeproject

========================================================
4. WHAT HAPPENS AFTER RUNNING THE COMMAND?
========================================================

Django automatically creates project folders and files.

========================================================
5. OUTPUT DIRECTORY STRUCTURE
========================================================

collegeproject/
│
├── manage.py
│
└── collegeproject/
    │
    ├── __init__.py
    ├── settings.py
    ├── urls.py
    ├── asgi.py
    └── wsgi.py

========================================================
6. IMPORTANT FILES EXPLANATION
========================================================

--------------------------------------------------------
a) manage.py
--------------------------------------------------------

Definition:
Used to run Django commands.

Examples:
    • Run server
    • Create app
    • Database migrations

Example Command:

python manage.py runserver

--------------------------------------------------------
b) settings.py
--------------------------------------------------------

Definition:
Contains all project settings.

Examples:
    • Database configuration
    • Installed apps
    • Security settings

--------------------------------------------------------
c) urls.py
--------------------------------------------------------

Definition:
Used to manage website URLs.

Example:

from django.urls import path

urlpatterns = [
]

--------------------------------------------------------
d) wsgi.py
--------------------------------------------------------

Definition:
Used for deploying Django applications on servers.

--------------------------------------------------------
e) asgi.py
--------------------------------------------------------

Definition:
Used for asynchronous server communication.

========================================================
7. HOW TO RUN THE PROJECT?
========================================================

Step 1:
Open terminal

Step 2:
Move inside project folder

cd collegeproject

Step 3:
Run server

python manage.py runserver

11. WHY CREATE PROJECT IS IMPORTANT?
========================================================

The project contains:
    • Website settings
    • Applications
    • Database configuration
    • URL management
    • Server configuration

Without project:
    • Django application cannot run
