========================================================
        INSTALL DJANGO – SIMPLE EXPLANATION
========================================================

Command:

pip install django

========================================================
1. WHAT IS DJANGO?
========================================================

Django is a high-level Python web framework used to build:
    • Websites
    • Web applications
    • APIs
    • Enterprise systems

Django is popular because it is:
    • Fast
    • Secure
    • Scalable

========================================================
2. WHAT IS pip?
========================================================

Full Form:
pip = Preferred Installer Program

--------------------------------------------------------
Definition
--------------------------------------------------------

pip is a package manager used in Python to install
Python libraries and frameworks.

Using pip you can install:
    • Django
    • NumPy
    • Pandas
    • Flask
    • TensorFlow

========================================================
3. INSTALL DJANGO COMMAND
========================================================

Command:

pip install django

--------------------------------------------------------
Meaning
--------------------------------------------------------

pip
    → Python package installer

install
    → Install package command

django
    → Django framework package

========================================================
4. HOW TO INSTALL DJANGO?
========================================================

--------------------------------------------------------
Step 1: Open Terminal / Command Prompt
--------------------------------------------------------

Windows:
    • Command Prompt
    • PowerShell

Linux/Mac:
    • Terminal

--------------------------------------------------------
Step 2: Type Command
--------------------------------------------------------

pip install django

--------------------------------------------------------
Step 3: Press Enter
--------------------------------------------------------

Python downloads and installs Django automatically.

========================================================
5. OUTPUT EXAMPLE
========================================================

Successfully installed django-5.x.x

--------------------------------------------------------
Possible Full Output
--------------------------------------------------------

Collecting django
Downloading django-5.x.x-py3-none-any.whl
Installing collected packages: django
Successfully installed django-5.x.x

========================================================
6. HOW TO CHECK DJANGO INSTALLED OR NOT?
========================================================

Command:

django-admin --version

========================================================
OUTPUT EXAMPLE
========================================================

5.2.1

--------------------------------------------------------
Meaning
--------------------------------------------------------

Shows installed Django version.

========================================================
7. CREATE DJANGO PROJECT
========================================================

Command:

django-admin startproject myproject

--------------------------------------------------------
Meaning
--------------------------------------------------------

django-admin
    → Django management tool

startproject
    → Create new Django project

myproject
    → Project name

========================================================
OUTPUT
========================================================

Project folder created:

myproject/
    manage.py
    myproject/

========================================================
8. RUN DJANGO SERVER
========================================================

Command:

python manage.py runserver

========================================================
OUTPUT
========================================================

Starting development server at:
http://127.0.0.1:8000/

--------------------------------------------------------
Meaning
--------------------------------------------------------

Django server started successfully.

========================================================
9. OPEN WEBSITE
========================================================

Open browser and visit:

http://127.0.0.1:8000/

========================================================
OUTPUT
========================================================

You will see:

"The install worked successfully!
Congratulations!"

This means Django is installed correctly.

========================================================
10. COMMON ERROR
========================================================

Error:

'pip' is not recognized as an internal or external command

--------------------------------------------------------
Reason
--------------------------------------------------------

Python is not installed properly or PATH not configured.

--------------------------------------------------------
Solution
--------------------------------------------------------

    • Install Python correctly
    • Enable "Add Python to PATH"
