========================================================
        MIGRATIONS IN DJANGO – SIMPLE EXPLANATION
========================================================

Definition:
Migration in Django is used to create and update database
tables automatically based on Django models.

Simple Meaning:
    • Models → Converted into Database Tables

Migrations help Django:
    • Create tables
    • Update tables
    • Modify database structure

========================================================
IMPORTANT MIGRATION COMMANDS
========================================================

+------------------+----------------------------------+
| Command          | Purpose                          |
+------------------+----------------------------------+
| makemigrations   | Create database change files     |
| migrate          | Apply changes to database        |
| sqlmigrate       | Show SQL queries of migrations   |
+------------------+----------------------------------+

========================================================
1. makemigrations
========================================================

Definition:
makemigrations creates migration files based on model
changes.

Simple Meaning:
    • Django detects model changes
    • Creates migration file automatically

========================================================
EXAMPLE
========================================================

Model:

from django.db import models

class Student(models.Model):
    name = models.CharField(max_length=100)
    age = models.IntegerField()

========================================================
COMMAND
========================================================

python manage.py makemigrations

========================================================
OUTPUT
========================================================

Migrations for 'app':
  app/migrations/0001_initial.py
    - Create model Student

========================================================
WHAT HAPPENS INTERNALLY?
========================================================

Django creates a migration file:

0001_initial.py

This file contains instructions for creating database
tables.

========================================================
WHY makemigrations IS IMPORTANT?
========================================================

Advantages:
    • Detects model changes
    • Creates migration files automatically
    • Avoids manual SQL writing

Result:
👉 Easier database management

========================================================
2. migrate
========================================================

Definition:
migrate applies migration files to the actual database.

Simple Meaning:
    • Creates tables inside database

========================================================
COMMAND
========================================================

python manage.py migrate

========================================================
OUTPUT
========================================================

Operations to perform:
  Apply all migrations

Running migrations:
  Applying app.0001_initial... OK

========================================================
WHAT HAPPENS INTERNALLY?
========================================================

Django creates database tables automatically.

Example Table Created:

+----+---------+-----+
| id | name    | age |
+----+---------+-----+

========================================================
WHY migrate IS IMPORTANT?
========================================================

Advantages:
    • Automatically creates tables
    • Updates database structure
    • Synchronizes models with database

Result:
👉 Database updated successfully

Easy memory trick:
    makemigrations = plan ready
    migrate = work done (database create/modify)

========================================================
3. sqlmigrate
========================================================

Definition:
sqlmigrate shows the actual SQL query generated by Django
migration.

Simple Meaning:
    • Converts Django migration into SQL query

========================================================
COMMAND
========================================================

python manage.py sqlmigrate app 0001

========================================================
EXPLANATION
========================================================

app
    → App name

0001
    → Migration number

========================================================
OUTPUT
========================================================

CREATE TABLE "app_student" (
    "id" integer NOT NULL PRIMARY KEY AUTOINCREMENT,
    "name" varchar(100) NOT NULL,
    "age" integer NOT NULL
);

========================================================
WHY sqlmigrate IS IMPORTANT?
========================================================

Advantages:
    • Shows actual SQL query
    • Helps understand database operations
    • Useful for debugging

Result:
👉 Developers can see SQL generated by Django
