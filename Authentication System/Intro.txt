========================================================
        AUTHENTICATION SYSTEM – SIMPLE EXPLANATION
========================================================

Definition:
Authentication is the process of verifying whether a user
is valid or not.

Django provides a built-in authentication system for:
    • Login
    • Logout
    • Registration
    • Permissions

========================================================
1. LOGIN
========================================================

Definition:
Login allows users to access the application using
username and password.

========================================================
LOGIN EXAMPLE
========================================================

from django.contrib.auth import authenticate, login

user = authenticate(
    username='ajay',
    password='mypassword'
)

if user is not None:
    login(request, user)

========================================================
EXPLANATION
========================================================

authenticate()
    → Checks username and password

login()
    → Logs user into application

========================================================
OUTPUT
========================================================

If correct credentials:

    User logged in successfully

If wrong password:

    Invalid username or password

========================================================
WHY LOGIN IS IMPORTANT?
========================================================

    • Protects private data
    • Allows secure access
    • Identifies valid users

========================================================
2. LOGOUT
========================================================

Definition:
Logout ends the current user session safely.

========================================================
LOGOUT EXAMPLE
========================================================

from django.contrib.auth import logout

logout(request)

========================================================
EXPLANATION
========================================================

logout()
    → Removes user session

========================================================
OUTPUT
========================================================

    User logged out successfully

========================================================
WHY LOGOUT IS IMPORTANT?
========================================================

    • Prevents unauthorized access
    • Protects user accounts
    • Ends active session securely

========================================================
3. REGISTER
========================================================

Definition:
Registration allows new users to create accounts.

========================================================
REGISTER EXAMPLE
========================================================

from django.contrib.auth.models import User

user = User.objects.create_user(
    username='ajay',
    password='mypassword123'
)

========================================================
EXPLANATION
========================================================

create_user()
    → Creates new user account

username
    → User login name

password
    → User secret password

========================================================
OUTPUT
========================================================

    New user account created successfully

========================================================
PASSWORD STORAGE
========================================================

Stored Password Example:

pbkdf2_sha256$260000$randomhash...

Passwords are encrypted automatically.

========================================================
WHY REGISTRATION IS IMPORTANT?
========================================================

    • Allows new users to join
    • Creates secure accounts
    • Stores user details safely

========================================================
4. PERMISSIONS
========================================================

Definition:
Permissions control what users can access or modify.

========================================================
EXAMPLE
========================================================

Some users can:
    • View data only

Some users can:
    • Add records
    • Edit records
    • Delete records

========================================================
PERMISSION CHECK EXAMPLE
========================================================

if request.user.is_staff:
    print("Admin Access")

========================================================
OUTPUT
========================================================

If admin user:

    Admin Access

If normal user:

    Access Denied

========================================================
WHY PERMISSIONS ARE IMPORTANT?
========================================================

    • Protects sensitive data
    • Restricts unauthorized actions
    • Provides role-based access
