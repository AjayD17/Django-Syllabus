1. WHAT IS MIDDLEWARE?
========================================================

Definition:
Middleware is a layer in Django that processes requests
before they reach the view and processes responses before
they are sent back to the user.

Simple Meaning:
Middleware works like a security/checking system between:
    • User Request
    • Django Server

========================================================
REQUEST FLOW
========================================================

User Request
      ↓
Middleware
      ↓
Django View
      ↓
Response
      ↓
Middleware
      ↓
User Browser

========================================================
WHY MIDDLEWARE IS IMPORTANT?
========================================================

Middleware helps Django to:
    • Improve security
    • Track users
    • Manage sessions
    • Process requests
    • Process responses

========================================================
2. REQUEST AND RESPONSE PROCESSING
========================================================

Definition:
Middleware checks incoming requests and outgoing responses.

========================================================
EXAMPLE
========================================================

Suppose a user opens:

http://127.0.0.1:8000/home/

--------------------------------------------------------
Request Processing
--------------------------------------------------------

Middleware checks:
    • User authentication
    • Security validation
    • Session information

before opening the page.

--------------------------------------------------------
Response Processing
--------------------------------------------------------

Before response reaches browser:
Middleware can:
    • Add headers
    • Compress data
    • Apply security rules

========================================================
OUTPUT
========================================================

User successfully opens:

Home Page Loaded Successfully

========================================================
3. SECURITY – CSRF PROTECTION
========================================================

Full Form:
CSRF = Cross-Site Request Forgery

--------------------------------------------------------
Definition
--------------------------------------------------------

CSRF protection prevents fake or malicious requests
from attackers.

========================================================
WHY CSRF IS IMPORTANT?
========================================================

Without CSRF:
    • Hackers may submit fake forms
    • User accounts may be misused

========================================================
EXAMPLE
========================================================

HTML Form:

<form method="POST">
    {% csrf_token %}

    <input type="text" name="username">

    <button type="submit">
        Submit
    </button>
</form>

========================================================
WHAT csrf_token DOES?
========================================================

Django generates a secret security token.

When form is submitted:
    • Django checks token validity

If token is correct:
    • Request accepted

If token missing:
    • Request blocked

========================================================
OUTPUT
========================================================

With valid token:

    Form submitted successfully

Without token:

    403 Forbidden Error

========================================================
4. SESSION HANDLING
========================================================

Definition:
Session handling is used to store user information
temporarily across multiple requests.

Simple Meaning:
Sessions help Django remember users after login.

========================================================
REAL-TIME EXAMPLE
========================================================

Suppose:
    • User logs into shopping website

Without sessions:
    • User must login again on every page

With sessions:
    • Django remembers logged-in user

========================================================
SESSION EXAMPLE
========================================================

Store session value:

request.session['username'] = 'Ajay'

--------------------------------------------------------
Retrieve session value
--------------------------------------------------------

username = request.session['username']

print(username)

========================================================
OUTPUT
========================================================

Ajay

========================================================
WHY SESSION HANDLING IS IMPORTANT?
========================================================

Advantages:
    • User tracking
    • Login persistence
    • Shopping cart management
    • Personalized user experience
